## Quick start

The SDK provides a single-coordinate facade (`dev.avinya.ads:admob-cmp`) for Android and iOS supporting six formats: Banner, Interstitial, Rewarded, Rewarded Interstitial, App Open, and Native. It includes pre-initialization hooks and consent control APIs for ordering ATT and UMP consent before initialising Google Mobile Ads, while production consent policies, store disclosures, and unit IDs are configured by the application.

<div class="landing-quickstart__pair">

```kotlin
// shared/build.gradle.kts
kotlin {
    sourceSets {
        commonMain.dependencies {
            implementation("dev.avinya.ads:admob-cmp:2.1.0")
        }
    }
}
```

```kotlin
// commonMain — initialize once at the root
adManager.gatherConsentAndInitialize(
    AdConfig(
        androidAppId = TestAdIds.ANDROID_APP_ID,
        iosAppId = TestAdIds.IOS_APP_ID,
        testMode = true,
    )
)
```

<div class="landing-quickstart__note">

On iOS, the SDK provides pre-initialization hooks and consent control APIs to order UMP consent and ATT tracking authorization before Mobile Ads initialization with `ConsentMode.InitializeOnlyIfAlreadyAllowed`. Applications configure production consent policies and store disclosures according to their requirements. See the [Quickstart guide](/start/quickstart/) and [iOS setup guide](/start/ios-setup/).
