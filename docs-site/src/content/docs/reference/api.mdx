## API reference

AdMob CMP exposes one Kotlin Multiplatform API for Google AdMob on Android and iOS. Most applications should depend on the `dev.avinya.ads:admob-cmp` facade and begin with the [Quickstart](/start/quickstart/); use the generated reference when you need exact signatures, types, or platform availability.

## Which module should I use?

| Need | Module |
|---|---|
| Standard Kotlin Multiplatform or Compose Multiplatform integration | `dev.avinya.ads:admob-cmp` |
| Controllers and state without Compose UI | `dev.avinya.ads:admob-cmp-core` |
| Compose views and composition helpers | `dev.avinya.ads:admob-cmp-compose` |
| Kotlin/Native iOS test-executable linkage | Apply plugin `dev.avinya.ads.admob-cmp` in the consuming build |

The Gradle plugin is build tooling rather than runtime API, so it has no Dokka module. It downloads and links the Google Mobile Ads and UMP iOS frameworks when a consumer runs Kotlin/Native test executables; the [Installation guide](/start/installation/) shows when it is required.

For setup requirements and supported toolchain versions, see [Installation](/start/installation/) and [Compatibility](/reference/compatibility/).
